# Dashboard

The Dashboard is a Next.js App Router/TypeScript application using Tailwind and shadcn/ui. It provides the overview and routed Finance, Tasks, Inbox, and Calendar pages. It consumes generated TypeScript OpenAPI types under `src/lib/api/generated`, not hand-written transport copies.

Browser requests use `/api/finance`, `/api/tasks`, `/api/inbox`, `/api/calendar`, and `/api/voice` relative to the current origin. Server-side rendering uses Docker service DNS internally. Loading/error handling is page-scoped so an unavailable service does not require exposing direct service ports.

The overview Voice capture control uses the browser `MediaRecorder` API. Stopping a recording uploads it to the asynchronous Voice job API and keeps the returned job ID in component state; it never waits for Whisper. “Accepted” means the audio has been durably queued, not that it was transcribed. The generated Voice client polls the persisted job and shows queued, processing, automatic-retry, succeeded, failed, or expired status; polling stops on terminal states and component cleanup clears the timer. Failed/expired uploads offer a re-record or re-send flow. A successful job means transcription completed and has been handed to Inbox; the Inbox widget remains the place to see later AI processing. Run `make dashboard-check` for format/lint/test/type/build and `make life-smoke` for browser-facing behavior.
