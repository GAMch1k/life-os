## Scope

Implemented: Finance, Tasks, Inbox, Calendar, Voice, and MCP services; PostgreSQL ownership/migrations; generated OpenAPI clients; a Next.js dashboard; Finance CSV import; a single Docker Nginx ingress; local authenticated Codex Inbox processing; and a private multilingual `whisper.cpp` worker. Voice recordings are queued asynchronously, transcribed, captured in Inbox, and can follow the same constrained MCP action path. Phase 8 added an attention-first Home, a Tasks workspace where undated Tasks stay visible, Task editing from both the Dashboard and the agent, Human Review for ambiguous changes, the Activity service and Event Log, a Status page with Codex usage, durable retry scheduling, and a hardened Codex runtime. See [Phase 8 verification](verification/phase-8.md). The routine AI profile was chosen by the [AI runtime benchmark](verification/ai-runtime-benchmark.md). Phase 10 made Calendar a full product: an editable event lifecycle with search, a FullCalendar workspace, AI and MCP parity for events, ICS feeds with ZAW waste collection, and Calendar in the Event Log, Home and Status. See [Phase 10 verification](verification/phase-10.md). Phase 12 adds the Notifications service: one path through which every service lets the owner know about something, stored for the Dashboard and delivered through server-configured channels. The monitor uses it to report a Status check that breaks or recovers; since 12 Oct 2026 notifications reach the phone through the Life OS Android app's push, and ntfy is paused. See [Phase 12 verification](verification/phase-12.md). Phase 14 adds the backup service: nightly consistent dumps of every service database (and the Inbox capture photos) on the host, rotated daily, weekly, and monthly, with a weekly restore check. See [Phase 14 verification](verification/phase-14.md). Phase 15 adds the Food service: one shopping list grouped by aisle with an optional store per item, aisle rules, and the pantry with expiry dates. Phase 17 adds the read-only host-health service: the shared server's memory, load, disks, and containers, and Life OS's own share, as the Server check on Status. See [Phase 17 verification](verification/phase-17.md).

Deferred: Android, Wear OS, public application authentication, external synchronization, and a general-purpose message bus. Android and Wear OS belong in separate repositories.

When a ticket changes behavior, API, configuration, networking, persistence, operations, or a user-visible flow, update the relevant page in this directory in the same branch.
